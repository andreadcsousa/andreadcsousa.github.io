# Andrea Sousa — Portfólio de Dados

Repositório central do meu portfólio profissional. Desenvolvido com foco em performance, design minimalista e sem dependências pesadas de frameworks, aplicando boas práticas de arquitetura front-end e semântica estrutural.

## 🎯 Objetivo do Projeto

Apresentar soluções consolidadas para ecossistemas de dados, demonstrando habilidades práticas na construção de fluxos automatizados, modelagem de dados analíticos e criação de painéis focados em Storytelling e suporte à tomada de decisão estratégica.

## 💻 Tecnologias Empregadas no Desenvolvimento

- **Estrutura:** HTML5 Semântico
- **Estilização & Layout:** CSS3 Moderno (CSS Variables, Flexbox e Grid Simétrico)
- **Interatividade:** JavaScript Vanilla (Manipulação dinâmica de DOM no Inspetor de Tech Stack)
- **Vetores:** SVG customizados inline para manter o carregamento ultra-rápido

## 📁 Estrutura de Pastas Essenciais

- `/assets/image/`: Armazenamento de ilustrações e componentes visuais.
- `index.html`: Ponto de entrada estrutural da aplicação.
- `style.css`: Arquivo de estilização contendo variáveis de escopo global e temas (Dark UI).
- `script.js`: Engine de comportamento dinâmico das seções.
